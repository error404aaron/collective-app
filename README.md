# COLLECTIVE (built app)

This repository contains only the compiled, static files of the COLLECTIVE Living City web app, served by GitHub Pages at https://error404aaron.github.io/collective-app/.

It is written automatically by the deployment workflow of the private source repository after every validated merge to main. Do not edit it by hand: each deploy replaces every file except this README. Each commit message names the source commit it was built from; build-info.json in the site does too.
